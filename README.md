# ИИ-администратор салона (демо)

Telegram-бот, который за салон:
- отвечает на вопросы про услуги, цены, адрес и часы — на русском, казахском и английском;
- записывает клиента (услуга, время, имя, телефон) и сразу присылает заявку владельцу в Telegram;
- не выдумывает цены: берёт их только из `salon.py`.

«Мозг» переключается одной настройкой `PROVIDER`:
- **gemini** — бесплатно (Google AI Studio). Для демо и тестов.
- **claude** — платно, оплата по факту. Для клиентов, когда бот должен работать стабильно.

## Файлы
| Файл | Что это |
|---|---|
| `salon.py` | Данные салона: услуги, цены, мастера, адрес. **Для нового клиента меняешь только его.** |
| `assistant.py` | Правила поведения бота и логика записи |
| `backends.py` | Подключение к ИИ (Gemini и Claude) |
| `bot.py` | Подключение к Telegram |
| `test_assistant.py` | Проверка логики без интернета: `python test_assistant.py` |

## Запуск бесплатно (15 минут)

1. **Бот.** В Telegram: @BotFather → `/newbot` → получи токен.
2. **Бесплатный ключ ИИ.** Зайди на aistudio.google.com под Google-аккаунтом → **Get API key** → создай ключ. Карта не нужна.
3. **Локально (проверить):**
   ```
   pip install -r requirements.txt
   cp .env.example .env      # впиши BOT_TOKEN и GEMINI_API_KEY, OWNER_CHAT_ID пока любой
   python bot.py
   ```
   Напиши своему боту `/id` → вставь число в `OWNER_CHAT_ID` → перезапусти.
4. **Railway (24/7):** залей папку на GitHub → New Project → Deploy from GitHub → во вкладке Variables добавь переменные из `.env.example`. `Procfile` уже есть.

## Ограничения бесплатного режима — важно
- **Лимит запросов в минуту и в день.** Для демо хватает с запасом, но при наплыве клиентов бот может начать отвечать «техническая заминка». Конкретные лимиты смотри в AI Studio — Google их меняет.
- **Google может использовать переписку бесплатного тарифа для улучшения своих продуктов.** Для демо на выдуманном салоне это неважно. Для реального клиента с телефонами и именами — переходи на платный режим.

## Когда появится первый клиент
Поменяй в Variables одну строку: `PROVIDER=claude` и добавь `ANTHROPIC_API_KEY` (platform.claude.com → API Keys, пополнение от $5). Код менять не нужно. Модель по умолчанию — Claude Haiku 4.5: $1 за миллион входящих и $5 за миллион исходящих токенов; один диалог с записью стоит доли цента. Расход оплачивается из подписки клиента.

## Как показать владельцу салона (3 минуты)

Не рассказывай — дай телефон в руки:
1. «Сколько стоит маникюр?» → цена из прайса.
2. «Қанша тұрады бояу?» → ответ по-казахски.
3. «Хочу на стрижку завтра в 6 вечера» → бот спросит имя, телефон и подтверждение.
4. Покажи свой телефон: заявка уже пришла.

Одна фраза в конце: *«Это работает ночью, в выходные и когда администратор занят. Под ваш салон настрою за день — с вашими ценами и мастерами.»*

## Под нового клиента
1. Возьми прайс (из Instagram или у владельца) → перепиши `salon.py`.
2. Новый бот в @BotFather с названием салона.
3. `OWNER_CHAT_ID` — chat id владельца или администратора (пусть напишет боту `/id`).
4. Отдельный сервис на Railway.

## Чего бот пока не умеет (честно говорить клиенту)
- Не видит расписание: собирает заявку, время подтверждает администратор. Подключение к YCLIENTS или календарю — платное дополнение.
- Только Telegram. WhatsApp и Instagram подключаются через их бизнес-API — отдельная работа и отдельная цена.
- История диалогов хранится в памяти и обнуляется при перезапуске.
